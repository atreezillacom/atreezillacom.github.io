**Цикли в C#** дозволяють виконувати один і той самий блок коду багато разів без дублювання. У мові є чотири види циклів: `for`, `while`, `do-while` і `foreach`. У статті розбираємо, як працює кожен із них, коли його обирати, і як керувати виконанням за допомогою `break` та `continue`.<!--more-->

## Який цикл обрати: швидка таблиця

| Цикл | Коли використовувати | Перевірка умови |
|------|----------------------|-----------------|
| `for` | Відома кількість ітерацій | Перед кожною ітерацією |
| `while` | Кількість ітерацій наперед невідома | Перед кожною ітерацією |
| `do-while` | Тіло має виконатися щонайменше раз | Після кожної ітерації |
| `foreach` | Обхід масиву чи колекції | Автоматично, до кінця колекції |

## Цикл for у C#

Цикл `for` використовують, коли відомо, скільки разів потрібно повторити дію. Заголовок складається з трьох частин: ініціалізація лічильника, умова продовження та зміна лічильника.

```csharp
for (int i = 0; i < 9; i++)
{
    if (i == 5)
        break; // повністю виходимо з циклу

    Console.Write(i);
}
// Результат: 01234
```

### break і continue

- `break` негайно завершує цикл.
- `continue` пропускає решту поточної ітерації та переходить до наступної.

```csharp
for (int i = 0; i < 9; i++)
{
    if (i % 2 == 0)
        continue; // пропускаємо парні числа

    Console.Write(i);
}
// Результат: 1357
```

## Цикл while у C#

Цикл `while` виконується, поки умова істинна. Умову перевіряють **до** входу в тіло, тому цикл може не виконатися жодного разу.

Приклад: виведення чисел від 5 до 1 у двійковому вигляді, доповнених нулями до 8 символів.

```csharp
int n = 5;
while (n > 0)
{
    Console.WriteLine(Convert.ToString(n, 2).PadLeft(8, '0'));
    n--;
}
```

> **Важливо:** якщо в тілі `while` не змінювати змінну з умови, цикл стане нескінченним.

## Цикл do-while у C#

У `do-while` умову перевіряють **після** виконання тіла, тож код виконається мінімум один раз. Це зручно для меню, введення з клавіатури та повторних спроб.

```csharp
int attempts = -1;
do
{
    Console.Write(attempts);
    attempts--;
} while (attempts > 0);
// Результат: -1 (тіло виконалося один раз, хоча умова хибна)
```

## Цикл foreach у C#

`foreach` перебирає елементи масиву або будь-якої колекції, що реалізує `IEnumerable`. Не потрібно стежити за індексами, тому код коротший і безпечніший.

```csharp
int[] numbers = new int[] { 1, 2, 3, 4, 5 };
foreach (int number in numbers)
{
    Console.Write(number);
}
// Результат: 12345
```

Змінна `foreach` доступна лише для читання: змінити елемент колекції через неї не можна. Також не можна додавати чи видаляти елементи колекції під час обходу, інакше виникне `InvalidOperationException`.

## Поширені помилки

1. **Нескінченний цикл**: умова ніколи не стає хибною (забули `i++` або `n--`).
2. **Помилка на одиницю (off-by-one)**: `i <= array.Length` замість `i < array.Length` призводить до виходу за межі масиву.
3. **Однакові імена змінних**: оголошення `int i` у кількох циклах в одній області видимості спричиняє помилку компіляції, тому використовуйте різні імена (`i`, `n`, `number`).
4. **Зміна колекції в `foreach`**: для видалення елементів використовуйте `for` у зворотному порядку або метод `RemoveAll`.

## Поширені запитання

**Чим відрізняється while від do-while?**
`while` перевіряє умову до виконання тіла, `do-while`: після, тому виконується щонайменше один раз.

**Коли краще використовувати foreach замість for?**
Коли потрібно просто пройти всі елементи без роботи з індексами. Якщо індекс потрібен або треба змінювати елементи, обирайте `for`.

**Що робить break у вкладених циклах?**
Завершує лише найближчий (внутрішній) цикл. Для виходу з кількох циклів використовують прапорець, `return` або `goto`.

**Як зробити нескінченний цикл у C#?**
`while (true) { ... }` або `for (;;) { ... }`. Вийти з нього можна через `break` або `return`.

## Підсумок

Для відомої кількості повторень обирайте `for`, для умовного повторення: `while`, для гарантованого першого виконання: `do-while`, а для обходу колекцій: `foreach`. Керуйте потоком за допомогою `break` та `continue`, і слідкуйте за умовою виходу, щоб уникнути нескінченних циклів.

**Читайте також:** умовні оператори `if`/`switch` у C#, масиви та колекції в C#, LINQ для обробки колекцій.
