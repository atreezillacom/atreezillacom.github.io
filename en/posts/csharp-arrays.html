Arrays in C#. Initialization

March 11, 2023

Described types of C# arrays (one-dimensional arrays, multidimensional arrays, array of arrays), methods of initializing arrays .

Single-Dimensional Arrays

var r1 = new int[3] { 1, 2, 3 };
var r2 = new int[] { 1, 2, 3 };
var r3 = new[] { 1, 2,  5 };
int[] r4 = { 1, 3, 5 };
r4[0] = 7;
for ( int i=0; i < r4.Length; i++ )
{
    Console.Write( r4[i] );
}

Multidimensional Arrays

int[,] r2 = new int[2, 3];

var r3 = new int[2, 3] 
   { { 0, 1, 2 }, { 3, 4, 5 } };

var r4 = new int[,] 
   { { 0, 1, 2 }, { 3, 4, 5 } };

var r5 = new [,]
   { { 0, 1, 2 }, { 3, 4, 5 } };

int[,] r6 = 
   { { 0, 1, 2 }, { 3, 4, 5 } };
   
r6[1,2] = 7;
Console.WriteLine("r6.Rank = {0} ", r3.Rank);

foreach (var i in r6){
    Console.Write("{0} ", i);
}
