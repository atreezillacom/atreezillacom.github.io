Масиви в C#: типи, створення та ініціалізація масивів

Масиви в C#: створення та ініціалізація масивів

Масиви в C# (Arrays) — це структури даних, які дозволяють зберігати декілька значень одного типу під одним ім’ям. Кожен елемент масиву має власний індекс, за допомогою якого можна отримати доступ до значення або змінити його.

Масиви є однією з базових структур даних у програмуванні на C#. Вони широко використовуються для роботи з наборами чисел, рядків, об’єктів, таблицями та іншими даними.

У C# масиви є об’єктами типу System.Array. Вони мають фіксований розмір, який визначається під час створення масиву та не може бути змінений протягом його існування.

У цій статті розглянемо:

  • Як створювати та ініціалізувати масиви в C#.
  • Які існують типи масивів.
  • Чим відрізняються одновимірні та багатовимірні масиви.
  • Що таке масив масивів (Jagged Arrays).
  • Як використовувати властивості Length, Rank та метод GetLength().
  • Як перебирати елементи масивів за допомогою циклів for та foreach.

1. Основи масивів у C#

Масив оголошується із зазначенням типу елементів та квадратних дужок [].

Загальний синтаксис:

тип[] ім'яМасиву;

Наприклад:

int[] numbers;
string[] names;
double[] prices;

У цих прикладах оголошено масиви для зберігання цілих чисел, рядків та чисел із плаваючою комою.

Важливо розуміти, що оголошення змінної масиву ще не створює сам масив. Для виділення пам’яті використовується оператор new.

int[] numbers = new int[5];

У цьому випадку створюється масив із п’яти елементів.

Індекси масиву починаються з нуля:

Індекс01234
Значення00000

Для числових типів значення елементів за замовчуванням дорівнює нулю, для bool — false, а для посилальних типів — null.

Доступ до елементів здійснюється за допомогою індексу:

int[] numbers = new int[3];

numbers[0] = 10;
numbers[1] = 20;
numbers[2] = 30;

Console.WriteLine(numbers[0]); // 10
Console.WriteLine(numbers[1]); // 20
Console.WriteLine(numbers[2]); // 30

Якщо звернутися до індексу, якого не існує, виникне виняток IndexOutOfRangeException.

2. Одновимірні масиви (Single-Dimensional Arrays)

Одновимірний масив — це впорядкована послідовність елементів одного типу, до яких можна звертатися за допомогою одного індексу.

Наприклад, масив із п’яти цілих чисел:

int[] numbers = new int[5];

Способи ініціалізації одновимірного масиву

У C# існує декілька способів створення та ініціалізації масивів.

1. Ініціалізація із зазначенням розміру та значень:

var r1 = new int[3] { 1, 2, 3 };

2. Ініціалізація із зазначенням типу без розміру:

var r2 = new int[] { 1, 2, 3 };

3. Ініціалізація з автоматичним визначенням типу:

var r3 = new[] { 1, 2, 5 };

Компілятор самостійно визначає тип масиву на основі типів елементів.

4. Скорочений синтаксис ініціалізації:

int[] r4 = { 1, 3, 5 };

Цей варіант дозволяє створити та ініціалізувати масив без явного використання оператора new.

Доступ до елементів масиву

Для читання та зміни значень використовуються індекси.

int[] numbers = { 1, 3, 5 };

numbers[0] = 7;

for (int i = 0; i < numbers.Length; i++)
{
    Console.Write(numbers[i] + " ");
}

Результат:

7 3 5

Властивість Length повертає загальну кількість елементів масиву.

Для перебору масиву також можна використовувати цикл foreach:

int[] numbers = { 1, 3, 5 };

foreach (int number in numbers)
{
    Console.WriteLine(number);
}

foreach зручний для послідовного читання елементів, але безпосередньо змінювати елементи масиву через змінну циклу не можна.

3. Багатовимірні масиви (Multidimensional Arrays)

Багатовимірні масиви дозволяють зберігати дані у вигляді таблиць або структур із декількома вимірами.

Найчастіше використовуються двовимірні масиви, які можна представити у вигляді таблиці з рядками та стовпцями.

Наприклад, двовимірний масив розміром 2 × 3:

      Стовпці
       0  1  2
     ┌─────────
Рядок 0│ 0  1  2
Рядок 1│ 3  4  5

Ініціалізація двовимірних масивів

Розглянемо декілька способів створення двовимірного масиву.

1. Створення масиву із зазначенням розмірності:

int[,] r1 = new int[2, 3];

Створюється масив із двох рядків та трьох стовпців. Усі елементи спочатку матимуть значення 0.

2. Ініціалізація із зазначенням розміру та значень:

var r2 = new int[2, 3]
{
    { 0, 1, 2 },
    { 3, 4, 5 }
};

3. Ініціалізація без зазначення розмірів:

var r3 = new int[,]
{
    { 0, 1, 2 },
    { 3, 4, 5 }
};

4. Скорочений запис:

int[,] r4 =
{
    { 0, 1, 2 },
    { 3, 4, 5 }
};

Доступ до елементів двовимірного масиву

Для звернення до елемента необхідно вказати два індекси: індекс рядка та індекс стовпця.

int[,] numbers =
{
    { 0, 1, 2 },
    { 3, 4, 5 }
};

numbers[1, 2] = 7;

Console.WriteLine(numbers[1, 2]); // 7

У цьому прикладі змінюється елемент другого рядка та третього стовпця.

Перебір елементів багатовимірного масиву

Для двовимірних масивів можна використовувати вкладені цикли for:

int[,] numbers =
{
    { 0, 1, 2 },
    { 3, 4, 5 }
};

for (int i = 0; i < numbers.GetLength(0); i++)
{
    for (int j = 0; j < numbers.GetLength(1); j++)
    {
        Console.Write(numbers[i, j] + " ");
    }

    Console.WriteLine();
}

Результат:

0 1 2
3 4 5

Також можна використовувати foreach, якщо необхідно послідовно отримати всі елементи:

foreach (var item in numbers)
{
    Console.Write(item + " ");
}

Результат:

0 1 2 3 4 5

Тривимірні та багатовимірні масиви

C# підтримує масиви з довільною кількістю вимірів.

Для оголошення тривимірного масиву використовується синтаксис int[,,].

int[,,] numbers = new int[2, 2, 3];

У цьому випадку створюється масив із трьома вимірами: 2 × 2 × 3.

Ініціалізувати його можна так:

int[,,] numbers =
{
    {
        { 0, 1, 2 },
        { 0, 1, 2 }
    },
    {
        { 3, 4, 5 },
        { 0, 1, 2 }
    }
};

Для доступу до елемента використовуються три індекси:

numbers[1, 0, 2] = 7;

Властивості Length, Rank та метод GetLength()

Для роботи з масивами в C# передбачені властивості та методи, які дозволяють отримувати інформацію про їхню структуру.

  • Length — загальна кількість елементів масиву.
  • Rank — кількість вимірів масиву.
  • GetLength(dimension) — кількість елементів у конкретному вимірі.

Розглянемо приклад:

int[,] numbers =
{
    { 0, 1, 2 },
    { 3, 4, 5 }
};

Console.WriteLine(numbers.Length);       // 6
Console.WriteLine(numbers.Rank);         // 2
Console.WriteLine(numbers.GetLength(0)); // 2
Console.WriteLine(numbers.GetLength(1)); // 3

Важливо: нумерація вимірів у GetLength() починається з нуля.

Для багатовимірного масиву загальна кількість елементів дорівнює добутку розмірів усіх вимірів.

Наприклад:

int[,,] numbers = new int[5, 2, 3];

int length = 1;

for (int i = 0; i < numbers.Rank; i++)
{
    Console.WriteLine(numbers.GetLength(i));

    length *= numbers.GetLength(i);
}

Console.WriteLine($"Calculated Length: {length}");
Console.WriteLine($"Array Length: {numbers.Length}");

Результат:

5
2
3
Calculated Length: 30
Array Length: 30

4. Масив масивів (Jagged Arrays)

Jagged Array (масив масивів) — це масив, елементами якого є інші масиви.

На відміну від звичайного двовимірного масиву, кожен вкладений масив може мати різну кількість елементів.

Наприклад:

Масив
  |
  ├── [0] → 1, 2
  |
  └── [1] → 1, 2, 3

Створення та ініціалізація Jagged Array

Для оголошення масиву масивів використовується подвійна пара квадратних дужок [][].

int[][] numbers = new int[2][];

numbers[0] = new int[] { 1, 2 };
numbers[1] = new int[] { 1, 2, 3 };

У цьому прикладі створюється масив із двох елементів, кожен із яких посилається на окремий масив.

Зверніть увагу: при створенні new int[2][] створюється лише зовнішній масив. Вкладені масиви необхідно ініціалізувати окремо.

Інший приклад:

var numbers = new int[3][];

numbers[0] = new int[] { 1, 2 };
numbers[1] = new int[] { 1 };
numbers[2] = new int[] { 4, 1, 2, 3, 5 };

У цьому випадку кожен вкладений масив має різну довжину.

Перебір елементів масиву масивів

Для перебору всіх елементів Jagged Array можна використовувати вкладені цикли foreach.

int[][] numbers =
{
    new int[] { 1, 2 },
    new int[] { 1, 2, 3 },
    new int[] { 4, 5, 6, 7 }
};

foreach (var row in numbers)
{
    foreach (var item in row)
    {
        Console.Write(item + " ");
    }

    Console.WriteLine();
}

Результат:

1 2
1 2 3
4 5 6 7

Комбінування різних типів масивів

C# дозволяє комбінувати масиви з різною кількістю вимірів.

Наприклад, char[][,] — це одновимірний масив, елементи якого є двовимірними масивами символів.

char[][,] words =
{
    new char[,]
    {
        { 'H', 'e' }
    },

    new char[,]
    {
        { 'l', 'l' },
        { 'o', ' ' }
    },

    new char[,]
    {
        { 'w', 'o' },
        { 'r', 'l' },
        { 'd', '!' }
    }
};

foreach (var matrix in words)
{
    foreach (var symbol in matrix)
    {
        Console.Write(symbol);
    }
}

Результат:

Hello world!

5. Порівняння типів масивів у C#

У C# можна використовувати три основні різновиди масивів: одновимірні, багатовимірні та масиви масивів.

Коли використовувати різні типи масивів?

Одновимірні масиви (int[])

Використовуйте, коли потрібно зберігати звичайну послідовність однотипних значень: список чисел, оцінок, ідентифікаторів або інших даних.

Багатовимірні масиви (int[,])

Підходять для роботи з таблицями, матрицями, координатними сітками та іншими структурами з фіксованою кількістю рядків і стовпців.

Масиви масивів (int[][])

Зручні, коли кількість елементів у кожному рядку може відрізнятися. Наприклад, для зберігання результатів опитувань, списків різної довжини або нерівномірних структур даних.

6. Типові помилки під час роботи з масивами C#

Під час використання масивів варто звернути увагу на декілька поширених помилок.

Помилка 1. Вихід за межі масиву

int[] numbers = { 1, 2, 3 };

Console.WriteLine(numbers[3]);

Індекси масиву починаються з нуля, тому для масиву з трьох елементів допустимі індекси 0, 1 та 2.

Спроба звернутися до numbers[3] призведе до IndexOutOfRangeException.

Правильний варіант:

for (int i = 0; i < numbers.Length; i++)
{
    Console.WriteLine(numbers[i]);
}

Помилка 2. Неініціалізовані вкладені масиви

int[][] numbers = new int[2][];

numbers[0][0] = 10;

У цьому прикладі зовнішній масив створено, але вкладений масив numbers[0] ще не ініціалізований. Спроба доступу призведе до NullReferenceException.

Правильний варіант:

int[][] numbers = new int[2][];

numbers[0] = new int[2];
numbers[0][0] = 10;

Помилка 3. Плутанина між Length та GetLength()

Для двовимірного масиву властивість Length повертає загальну кількість елементів, а не кількість рядків або стовпців.

int[,] numbers = new int[2, 3];

Console.WriteLine(numbers.Length);       // 6
Console.WriteLine(numbers.GetLength(0)); // 2
Console.WriteLine(numbers.GetLength(1)); // 3

Використовуйте GetLength(), коли необхідно отримати розмір конкретного виміру.

7. Часті запитання про масиви в C# (FAQ)

Що таке масив у C#?

Масив — це структура даних, яка зберігає фіксовану кількість елементів одного типу. Доступ до елементів здійснюється за допомогою індексів, які починаються з нуля.

Як оголосити масив у C#?

Для оголошення масиву використовується тип даних та квадратні дужки:

int[] numbers;

Для створення масиву з п’яти елементів:

int[] numbers = new int[5];

Чим відрізняється багатовимірний масив від Jagged Array?

Багатовимірний масив має фіксовану кількість елементів у кожному вимірі. Jagged Array складається з вкладених масивів, які можуть мати різну довжину.

Що повертає властивість Length?

Length повертає загальну кількість елементів масиву незалежно від кількості його вимірів.

Що означає Rank у C#?

Rank — це властивість, яка повертає кількість вимірів масиву. Наприклад, для int[] значення дорівнює 1, для int[,] — 2, а для int[,,] — 3.

Чи можна змінити розмір масиву після створення?

Ні. Розмір масиву фіксується під час створення. Якщо потрібно змінити кількість елементів, можна створити новий масив або скористатися колекцією List<T>, яка підтримує динамічне збільшення та зменшення розміру.

8. Практичні завдання для закріплення матеріалу

Для кращого розуміння роботи з масивами рекомендується виконати декілька практичних завдань.

  1. Одновимірний масив. Створіть масив із десяти цілих чисел. Заповніть його значеннями та знайдіть максимальний і мінімальний елементи.

  2. Сортування масиву. Реалізуйте алгоритм сортування одновимірного масиву за зростанням без використання готових методів сортування.

  3. Двовимірний масив. Створіть матрицю розміром 3 × 3. Обчисліть суму елементів кожного рядка та кожного стовпця.

  4. Транспонування матриці. Створіть двовимірний масив і сформуйте новий масив, у якому рядки та стовпці поміняні місцями.

  5. Jagged Array. Створіть масив масивів із різною кількістю елементів. Знайдіть суму всіх елементів та найбільший елемент.

  6. Багатовимірні масиви. Створіть тривимірний масив та виведіть розмір кожного виміру за допомогою GetLength().

Висновок

Масиви є фундаментальною структурою даних у C#, яка дозволяє ефективно працювати з наборами однотипних значень.

Основні типи масивів:

  • Одновимірні масиви (int[]) — для зберігання послідовностей елементів.
  • Багатовимірні масиви (int[,], int[,,]) — для роботи з таблицями та матрицями.
  • Масиви масивів (int[][]) — для зберігання вкладених масивів різної довжини.

Розуміння принципів створення, ініціалізації та перебору масивів є важливою основою для подальшого вивчення колекцій C#, LINQ та алгоритмів обробки даних.
