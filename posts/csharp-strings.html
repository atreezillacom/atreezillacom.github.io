Рядки в C#: створення , методи , форматування та приклади

Рядки (strings) у C# один із базових типів даних, який використовується для зберігання та обробки текстової інформації. За допомогою рядків можна працювати з іменами, повідомленнями, адресами, файлами, датами, числовими значеннями та іншими текстовими даними.

Рядки в C#: створення, методи та форматування

У C# для роботи з рядками використовується клас String із простору імен System. Тип string є псевдонімом System.String, тому їх можна використовувати взаємозамінно.

У цій статті розглянемо, як створювати та ініціалізувати рядки в C#, які методи класу String використовуються найчастіше, як порівнювати та форматувати текст, а також як працювати зі спеціальними символами.

1. Ініціалізація рядків у C

У C# існує декілька способів створення рядків. Найпростіший варіант – присвоїти змінній текстове значення в подвійних лапках.

string s1 = "hello";
string s2 = null;

string s3 = new string('a', 6);
// Результат: "aaaaaa"

string s4 = new string(new char[]
{
    'w', 'o', 'r', 'l', 'd'
});
// Результат: "world"

string s5 = string.Empty;
// Порожній рядок

Розглянемо основні варіанти ініціалізації:

  • string s = "Hello"; — створення рядка з текстовим значенням.
  • string s = null; — змінна не посилається на об’єкт рядка.
  • string s = string.Empty; — створення порожнього рядка.
  • new string('a', 6) — створення рядка з повторюваних символів.
  • new string(char[]) — створення рядка на основі масиву символів.

Перевірка рядка на null або порожнє значення

Для перевірки рядків у C# передбачені спеціальні статичні методи:

  • string.IsNullOrEmpty() — перевіряє, чи є значення null або порожнім рядком.
  • string.IsNullOrWhiteSpace() — додатково перевіряє рядки, що містять лише пробільні символи.

Приклад:

string text = "   ";

if (string.IsNullOrWhiteSpace(text))
{
    Console.WriteLine("Empty String");
}

if (string.IsNullOrEmpty(text))
{
    Console.WriteLine("String is null or empty");
}

Важливо: методи IsNullOrEmpty() та IsNullOrWhiteSpace() викликаються через клас string, а не через змінну.

2. Основні методи класу String

Клас String містить багато методів для пошуку, порівняння, об’єднання та зміни тексту.

Найчастіше використовуються такі методи:

Метод Призначення

Compare() Порівнює два рядки з урахуванням правил культури CompareOrdinal() Порівнює рядки за значеннями символів Contains() Перевіряє наявність підрядка Concat() Об’єднує декілька рядків EndsWith() Перевіряє закінчення рядка StartsWith() Перевіряє початок рядка Format() Форматує рядок IndexOf() Знаходить індекс першого входження LastIndexOf() Знаходить індекс останнього входження Insert() Вставляє підрядок у задану позицію Join() Об’єднує елементи колекції роздільником Replace() Замінює частину рядка Split() Розділяє рядок на масив Substring() Отримує частину рядка ToLower() Перетворює символи на нижній регістр ToUpper() Перетворює символи на верхній регістр Trim() Видаляє пробільні символи на початку та в кінці TrimStart() Видаляє символи на початку TrimEnd() Видаляє символи в кінці

Приклади використання методів String

Contains() — перевірка наявності тексту

string text = "Hello World";

bool result = text.Contains("World");

Console.WriteLine(result); // True

Replace() — заміна тексту

string text = "Hello World";

string result = text.Replace("World", "C#");

Console.WriteLine(result); // Hello C#

Split() — розділення рядка

string text = "C#;Java;Python";

string[] languages = text.Split(';');

foreach (string language in languages)
{
    Console.WriteLine(language);
}

Join() — об’єднання елементів масиву

string[] languages = { "C#", "Java", "Python" };

string result = string.Join(", ", languages);

Console.WriteLine(result);
// C#, Java, Python

Substring() — отримання частини рядка

string text = "Programming";

string result = text.Substring(0, 7);

Console.WriteLine(result); // Program

IndexOf() — пошук позиції символу або підрядка

string text = "Hello World";

int index = text.IndexOf("World");

Console.WriteLine(index); // 6

3. Порівняння рядків у C

Для порівняння рядків у C# можна використовувати оператори ==, !=, а також методи Equals(), Compare() та CompareOrdinal().

Приклад:

string first = "Hello";
string second = "Hello";

Console.WriteLine(first == second); // True
Console.WriteLine(first.Equals(second)); // True

За замовчуванням порівняння рядків чутливе до регістру.

string first = "Hello";
string second = "hello";

Console.WriteLine(first == second); // False

Для порівняння без урахування регістру рекомендується використовувати StringComparison:

string first = "Hello";
string second = "hello";

bool result = string.Equals(
    first,
    second,
    StringComparison.OrdinalIgnoreCase
);

Console.WriteLine(result); // True

Основні варіанти порівняння:

  • StringComparison.Ordinal — порівняння за значеннями символів.
  • StringComparison.OrdinalIgnoreCase — порівняння без урахування регістру.
  • StringComparison.CurrentCulture — порівняння відповідно до поточної культури.
  • StringComparison.CurrentCultureIgnoreCase — порівняння відповідно до поточної культури без урахування регістру.

Для технічних ідентифікаторів, ключів, назв файлів та інших програмних значень зазвичай краще використовувати Ordinal або OrdinalIgnoreCase.

4. Форматування рядків у C

Форматування рядків дозволяє перетворювати числові, грошові та інші значення на текст у потрібному вигляді.

У C# існує декілька основних способів форматування:

  • ToString() — перетворення значення на рядок.
  • String.Format() — форматування за допомогою індексів.
  • Інтерполяція рядків $"..." — вставлення змінних безпосередньо в текст.

Форматування за допомогою ToString()

long number1 = 19876543210L;

Console.WriteLine(
    number1.ToString("+0 (000) 000-00-00")
);

// +1 (987) 654-32-10

У прикладі використовується спеціальний числовий формат, який задає відображення числа за шаблоном.

Форматування за допомогою інтерполяції

Інтерполяція рядків дозволяє вставляти значення змінних безпосередньо в текст.

long number1 = 19876543210L;

Console.WriteLine($"{number1:+# ### ### ## ##}");

// +1 987 654 32 10

Цей спосіб зручний для формування повідомлень, логів та текстових представлень даних.

Форматування за допомогою String.Format()

double number = 23.7;

string result = string.Format("{0:C}", number);

Console.WriteLine(result);

Формат C означає Currency — грошовий формат.

Результат залежить від поточної культури системи. Наприклад, символ валюти та роздільник дробової частини можуть відрізнятися.

5. Стандартні специфікатори числових форматів

У C# для форматування числових значень використовуються стандартні специфікатори.

Специфікатор Назва Призначення

C / c Currency Грошовий формат D / d Decimal Цілочисельний формат E / e Exponential Експоненційне подання F / f Fixed-point Дробове число з фіксованою точкою G / g General Загальний формат N / n Number Числовий формат із роздільниками груп P / p Percent Відображення відсотків X / x Hexadecimal Шістнадцятковий формат

Приклади:

double number = 1234.5678;

Console.WriteLine(number.ToString("C"));
Console.WriteLine(number.ToString("F2"));
Console.WriteLine(number.ToString("N2"));
Console.WriteLine(number.ToString("P"));
Console.WriteLine(number.ToString("E"));

Можна також задавати кількість знаків після десяткової крапки:

double number = 23.45678;

Console.WriteLine(number.ToString("F2"));
// 23.46

Console.WriteLine(number.ToString("N3"));
// 23.457

Зверніть увагу: D застосовується до цілих чисел, а X дозволяє отримати шістнадцяткове представлення числа.

6. Спеціальні символи та escape-послідовності

У рядках C# деякі символи мають спеціальне значення. Для їх відображення використовуються escape-послідовності — комбінації символів, що починаються зі зворотної косої риски \.

Основні escape-послідовності:

Послідовність Значення

\' Одинарна лапка \" Подвійна лапка \\ Зворотна коса риска \0 Нульовий символ \a Звуковий сигнал \b Backspace \f Перехід сторінки (Form Feed) \n Новий рядок \r Повернення каретки \t Горизонтальна табуляція \v Вертикальна табуляція

Приклад:

string text = "Hello\nWorld";

Console.WriteLine(text);

Результат:

Hello
World

Unicode-символи

C# підтримує Unicode-послідовності для представлення символів різних мов та спеціальних знаків.

Послідовність Призначення

\u Unicode-код символу у форматі UTF-16 \U Unicode-код символу у форматі UTF-32 \x Шістнадцяткове представлення символу

Приклади:

string text1 = "\u00E7";

Console.WriteLine(text1); // ç

string text2 = "\U0001F47D";

Console.WriteLine(text2); // 👽

Для \u використовується чотири шістнадцяткові цифри, для \U — вісім.

Послідовність \x може містити від однієї до чотирьох шістнадцяткових цифр.

7. Рядки з інтерполяцією, дослівні та багаторядкові рядки

C# підтримує декілька способів запису рядкових літералів.

Звичайні рядки

string text = "Hello World";

У звичайних рядках спеціальні символи записуються за допомогою escape-послідовностей.

Дослівні рядки (Verbatim Strings)

Для створення дослівного рядка використовується символ @.

string path = @"C:\Users\Admin\Documents\file.txt";

Console.WriteLine(path);

У таких рядках зворотна коса риска не потребує екранування.

Інтерполяція рядків

Для вставлення змінних у текст використовується символ $.

string name = "Alex";
int age = 25;

string result = $"Name: {name}, Age: {age}";

Console.WriteLine(result);

Можна комбінувати інтерполяцію з дослівними рядками:

string path = $@"C:\Users\{name}\Documents";

Багаторядкові рядкові літерали

Починаючи з C# 11, можна використовувати raw string literals — багаторядкові рядки з потрійними лапками.

string json = """
{
    "name": "Alex",
    "language": "C#"
}
""";

Console.WriteLine(json);

Це особливо зручно для JSON, SQL-запитів, HTML та інших текстових структур.

8. Незмінність рядків (String Immutability)

Важливою особливістю типу string у C# є незмінність (immutability).

Це означає, що після створення рядка його вміст не можна змінити. Методи на кшталт Replace(), ToUpper() та Trim() повертають новий рядок, а не змінюють початковий.

Приклад:

string text = "hello";

text.ToUpper();

Console.WriteLine(text);
// hello

Щоб зберегти результат перетворення, необхідно присвоїти його змінній:

string text = "hello";

text = text.ToUpper();

Console.WriteLine(text);
// HELLO

Ця особливість важлива під час роботи з великими обсягами тексту та великою кількістю операцій об’єднання рядків.

9. StringBuilder — ефективне об’єднання рядків

Якщо потрібно багаторазово змінювати текст або об’єднувати велику кількість рядків, рекомендується використовувати клас StringBuilder із простору імен System.Text.

На відміну від string, StringBuilder дозволяє змінювати вміст об’єкта без створення нового рядка після кожної операції.

Приклад:

using System.Text;

StringBuilder builder = new StringBuilder();

builder.Append("Hello");
builder.Append(" ");
builder.Append("World");

builder.AppendLine("!");

string result = builder.ToString();

Console.WriteLine(result);

Основні методи StringBuilder:

  • Append() — додає текст у кінець.
  • AppendLine() — додає текст із переходом на новий рядок.
  • Insert() — вставляє текст у задану позицію.
  • Replace() — замінює частину тексту.
  • Remove() — видаляє частину тексту.
  • Clear() — очищає вміст.

Для простого об’єднання декількох рядків цілком достатньо оператора + або інтерполяції. StringBuilder найбільш корисний у циклах та сценаріях із великою кількістю послідовних змін тексту.

10. Перетворення рядків на числа

Під час роботи з користувацьким введенням, файлами та API часто виникає необхідність перетворити рядок на числове значення.

Для цього використовуються методи Parse() та TryParse().

Використання Parse()

string text = "123";

int number = int.Parse(text);

Console.WriteLine(number);

Якщо рядок не містить коректного числового значення, Parse() може викликати виняток FormatException.

Використання TryParse()

Безпечніший варіант — TryParse(), який повертає результат перетворення через параметр out.

string text = "123";

if (int.TryParse(text, out int number))
{
    Console.WriteLine(number);
}
else
{
    Console.WriteLine("Invalid number");
}

TryParse() особливо зручний під час перевірки даних, введених користувачем.

11. Часті помилки під час роботи з рядками C

Під час роботи з рядками варто звертати увагу на декілька поширених помилок:

  1. Порівняння без урахування регістру. Рядки "Hello" та "hello" за замовчуванням вважаються різними.
  2. Відсутність перевірки на null. Виклик методів у змінної зі значенням null може призвести до NullReferenceException.
  3. Неправильне використання StringBuilder. Для простих операцій його використання не завжди виправдане.
  4. Ігнорування культури. Формати чисел і грошових значень залежать від регіональних налаштувань.
  5. Надмірне використання конкатенації. Багаторазове об’єднання рядків у циклах може створювати зайві об’єкти в пам’яті.

12. Часті запитання про рядки в C

Що таке string у C#?

string — це псевдонім класу System.String, який використовується для зберігання та обробки текстових даних.

Чим відрізняються string і String?

Функціональної різниці немає. string — ключове слово C#, а String — назва класу з простору імен System. У повсякденному коді зазвичай використовують string.

Чим відрізняються null та string.Empty?

null означає відсутність посилання на об’єкт рядка. string.Empty — це існуючий рядок із нульовою довжиною.

Як перевірити, чи порожній рядок у C#?

Для цього можна використовувати string.IsNullOrEmpty(). Якщо потрібно також перевіряти рядки, що містять лише пробіли, використовуйте string.IsNullOrWhiteSpace().

Чи можна змінити рядок після його створення?

Ні. Тип string є незмінним. Методи зміни тексту повертають новий рядок. Для багаторазової зміни тексту можна використовувати StringBuilder.

Що краще використовувати: StringBuilder чи конкатенацію?

Для невеликої кількості операцій зручно використовувати оператор + або інтерполяцію. Для багаторазового об’єднання та зміни тексту, особливо в циклах, краще використовувати StringBuilder.

Висновок

Рядки в C# є важливою частиною мови програмування та використовуються практично в кожному застосунку. Клас String надає широкий набір методів для пошуку, порівняння, форматування та обробки тексту.

Для ефективної роботи з рядками важливо розуміти принцип їх незмінності, вміти використовувати інтерполяцію, стандартні формати чисел, спеціальні символи та StringBuilder.

Знання цих можливостей допоможе писати більш зрозумілий, ефективний та надійний код на C#.
